# Senior Software Developer

**React · Vue · Node.js**

I build web products from the interface through the API — media platforms, operator dashboards, commerce flows, and the admin tools around them.

</div>

---

## Focus

**Interfaces.** React, Next.js, Vue 3, Nuxt, and Quasar. State stays explicit with Redux, Zustand, or Pinia, and Tailwind is the styling layer when the product needs one.

**Services.** Node.js and Express for authentication, admin, schedules, and the data those screens depend on. MongoDB is the database behind most of the public APIs.

**Products.** Live and on-demand media, AI messaging and conversational agents, storefronts and booking, healthcare access and payments, facility operations, and veterinary wellness.
